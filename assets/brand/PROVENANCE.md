# Fulcrum 品牌資產

本目錄是當前採用版本的完整自包含副本：源圖、成品、提示詞與字體各一份。

## 當前檔案

| 檔案 | 用途 |
|---|---|
| `fulcrum-logo-source.png` | 採用的 Logo 原生源或品牌定稿源 |
| `fulcrum-logo.png` | 1024×1024 透明 Logo 定稿 |
| `fulcrum-badge-bg-source.png` | 橫版原生無字源圖 |
| `fulcrum-badge-bg.webp` | 1248×416 無字橫版背景 |
| `fulcrum-badge.webp` | 1248×416 帶字橫版定稿 |
| `fulcrum-stage-bg-source.png` | 豎版原生無字源圖 |
| `fulcrum-stage-bg.webp` | 1280×1600 無字豎版背景 |
| `fulcrum.webp` | 1280×1600 帶字豎版定稿 |
| `prompts-fulcrum.md` | Logo、橫版、豎版提示詞與合成規範 |
| `fonts/` | 實際合成使用的字體與現有授權文字 |

## 字體

HarmonyOS Sans SC Bold 用於中文主標，Geist Mono Variable 用於 Fulcrum；字體原件與來源說明一併保存。

## 版本紀律

這裡只保留當前採用版本。被否決的生成結果、帶 `v1` / `v2` 的過渡命名和舊建置中間圖不保留；需要重現時以本目錄的源圖與提示詞為準。
