# Fulcrum brand assets

This directory contains the adopted source images, rendered artwork and fonts.

| File | Purpose |
| --- | --- |
| `fulcrum-logo-source.png` | Adopted logo source. |
| `fulcrum-logo.png` | Transparent 1024 × 1024 logo. |
| `fulcrum-badge-bg-source.png` | Landscape source without text. |
| `fulcrum-badge-bg.webp` | 1248 × 416 landscape background. |
| `fulcrum-badge.webp` | 1248 × 416 final landscape artwork. |
| `fulcrum-stage-bg-source.png` | Portrait source without text. |
| `fulcrum-stage-bg.webp` | 1280 × 1600 portrait background. |
| `fulcrum.webp` | 1280 × 1600 final portrait artwork. |
| `fonts/` | Font files and their existing source/license notices. |

HarmonyOS Sans SC Bold supplies the Chinese display text; Geist Mono Variable
supplies the Fulcrum wordmark. Preserve the original font files and accompanying
source/license notices. Use the adopted source images when preparing new exports;
keep replaced candidates and working intermediates outside this directory.
