# Fulcrum 品牌资产

本目录是当前采用版本的完整自包含副本：源图、成品、提示词与字体各一份。

## 当前文件

| 文件 | 用途 |
|---|---|
| `fulcrum-logo-source.png` | 采用的 Logo 原生源或品牌定稿源 |
| `fulcrum-logo.png` | 1024×1024 透明 Logo 定稿 |
| `fulcrum-badge-bg-source.png` | 横版原生无字源图 |
| `fulcrum-badge-bg.webp` | 1248×416 无字横版背景 |
| `fulcrum-badge.webp` | 1248×416 带字横版定稿 |
| `fulcrum-stage-bg-source.png` | 竖版原生无字源图 |
| `fulcrum-stage-bg.webp` | 1280×1600 无字竖版背景 |
| `fulcrum.webp` | 1280×1600 带字竖版定稿 |
| `prompts-fulcrum.md` | Logo、横版、竖版提示词与合成规范 |
| `fonts/` | 实际合成使用的字体与现有授权文本 |

## 字体

HarmonyOS Sans SC Bold 用于中文主标，Geist Mono Variable 用于 Fulcrum；字体原件与来源说明一并保存。

## 版本纪律

这里只保留当前采用版本。被否决的生成结果、带 `v1` / `v2` 的过渡命名和旧构建中间图不保留；需要复现时以本目录的源图与提示词为准。
