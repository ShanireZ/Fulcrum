★ **权威是 [`PLAN.md`](../../PLAN.md)**：§11 的 `D9` 是这件事本身，§10 的 `G141` 是本页的授权决定。
本页只回答一个问题：**改动落在哪个面上、算不算 breaking。**

## 一、承诺从什么时候起

⛔ **现在没有兼容性承诺**，这一条不由本页改动 —— 它写在 [`PLAN.md`](../../PLAN.md) §7 的 M4 一节里。
本页给出的是**分类法**，不是承诺：它让「这个改动以后会不会很贵」在今天就答得出来，
而不是等到承诺生效那天再来吵一遍。

★ ★ **为什么现在写、却不现在承诺**：`G129` 把 `id` 的取值域收紧成 `[A-Za-z0-9_.-]`，
理由逐字是「D9 还没结案、M4 之前没有任何兼容性承诺 ⇒ **要收就现在收最便宜**」。
那个自由度今天仍然需要 —— 提前上承诺等于把它收掉。
⇒ **分类法今天生效（用来估价），承诺 M4 起生效（用来约束）。**

## 二、五个面，各自的 breaking 长得不一样

⚠ **「对外」指的是这个项目之外的人或机器依赖的东西。** 六个 crate 全是 `publish = false`，
没有 crates.io 下游 ⇒ **Rust 层面的 API 不是对外面**，跨 crate 改签名不进这张表。

| 面 | 谁在消费 | 什么算 breaking |
|---|---|---|
| **DSL** | 人手写的配置文件 | 曾经编得过的配置现在编不过；或**编得过但行为不同** |
| **结构化配置**（`POST /load`）| 机器生成的 JSON | 曾经装得上的 payload 现在被拒 |
| **`/stats` JSON** | 运维脚本、看板 | 删字段、改字段语义、改类型。⚠ **加**字段不算 |
| **指标名与标签** | Prometheus 告警与看板 | 改族名、删族、删标签、收窄标签值域。⚠ **加**族、**加**样本不算 |
| **`FUL-DSL-NNNN`** | 文档与自动化 | 一旦发出就不能改含义 |

⚠ **DSL 那一行的后半句是重点**：「编得过但行为不同」比「编不过」**贵得多** ——
编不过会当场停在 `fulcrum validate`，行为不同则要等到线上才发现。
⇒ 判断一个 DSL 改动时，先问的不是「还编得过吗」，是「同一份配置的行为变了没有」。

⚠ **`FUL-DSL-NNNN` 那一行不是本页新加的承诺**：
[`dsl-reference.md`](/architecture/dsl-reference.md) 早就写着这些码稳定、可被文档与自动化引用。
本页只是把它归到同一张表里，⛔ 不得与之矛盾。

## 三、★ 指标那一面最贵，理由与别处不同

改一个指标名，**不会有任何东西报错**：
配置照样装、请求照样过、门禁照样绿。只有别人的告警规则**静默地不再匹配**，
而「告警没响」和「一切正常」在监控台上长得一模一样。

⇒ 它与本仓反复踩的那一族是同一个物种：**一个「没有」既可能是真没有，也可能是量具够不着。**
⇒ 纪律：**改指标名与标签，按最高档处理**，⛔ 不因为「反正编译得过」就当成小事。

★ 反过来，**加**一个族或一条样本是安全的：没有人的告警会因为多了一个族而失效。
⇒ 这条不对称正是这张表按「删/改 vs 加」分界的理由，不是随手定的。

## 四、构建身份 ≠ 版本承诺

`fulcrum_build_info{version}` 回答的是「**跑的是哪一次构建**」，
⛔ **不是**「这个版本承诺了什么」。两件事共用一个字符串会让人把前者读成后者。

⇒ 取值用 semver 的**构建元数据**语法（`+` 之后那一段）：按 semver 自己的规矩，
`+` 后面的内容**不参与版本先后比较** —— 语法本身就在声明「这是身份，不是承诺」。

取值链，从左到右第一个取得到的赢：

| | 来源 | 用在哪 |
|---|---|---|
| ① | `FULCRUM_BUILD_ID` 环境变量 | 打包与发布：由构建环境喂真值 |
| ② | `git describe` 推导 | 日常开发与门禁 |
| ③ | 显式 `unknown` | 前两个都取不到时 |

⛔ ★ **第三档必须是显式的 `unknown`，不许悄悄退回 `0.0.0`。**
「读不到」与「读到了 0.0.0」是两件事，而后者会让人以为自己看到了一个真实的版本号
—— 与本仓「没能检查不算检查通过」是同一条纪律。

## 五、本页不回答的

- **版本号怎么排**（`0.x` 还是 `1.0`、什么时候进位）—— 属于 `D9` 仍然开着的那一半，挂 M4。
- **弃用要给多久的过渡期** —— 同上。
- **`vendor/pingora/` 的 fork 改动** —— 那由 [`FORK.md`](../../vendor/pingora/FORK.md) 管，
  它跟随上游而不是跟随本项目的承诺。
