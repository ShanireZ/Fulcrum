# 两条读法

**「等 X 发生就到期」的登记，没有任何东西会在 X 发生时通知它。**
D22 的到期条件满足了四轮才被发现，而这四轮里每一轮都读过这张表。
⇒ 到期条件要么挂进一道门，要么写成「每轮都要看一眼」的那种检查。

**一条待定项被拍板时，答案未必是它问的那个问题。**
D22 登记的是「探针何时变成常设的门」，而 owner 换掉的是**判据本身** ——
探针编的是 spike，答不了「产物是不是单静态二进制」。
⇒ 结案时先回头看这一条问的到底是什么。
