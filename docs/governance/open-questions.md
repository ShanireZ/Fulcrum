# 兩條讀法

**「等 X 發生就到期」的登記，沒有任何東西會在 X 發生時通知它。**
D22 的到期條件滿足了四輪才被發現，而這四輪裡每一輪都讀過這張表。
⇒ 到期條件要麼掛進一道門，要麼寫成「每輪都要看一眼」的那種檢查。

**一條待定項被拍板時，答案未必是它問的那個問題。**
D22 登記的是「探針何時變成常設的門」，而 owner 換掉的是**判據本身** ——
探針編的是 spike，答不了「產物是不是單靜態二進位」。
⇒ 結案時先回頭看這一條問的到底是什麼。
