# Documentation authority

[PLAN.md](../../PLAN.md) owns scope, milestone state/exits, G-decisions and open D-questions. Approved G-decisions take precedence over conflicting narrative; open D-questions are not requirements.

[Architecture](../architecture/index.md) contains the technical baseline and yields to PLAN. [FORK.md](../../vendor/pingora/FORK.md) owns fork deltas. Source/schema/command help own implementation details. Other docs navigate these sources rather than creating independent progress or decision registers. README and AGENTS retain stable identity/contracts and link to PLAN for changing status.

Keep temporary operating/authorization/localization records outside Git. Historical raw benchmark data retains its measured scope and immutable identity; it cannot certify later code. Repair conflicting documentation at its owning source rather than keeping two incompatible conclusions.
