# Positioning

[PLAN §2–3](../../PLAN.md) owns positioning: one Rust static binary combining web serving, reverse proxy and load balancing for fleet and self-hosted deployments. Fulcrum is a data-plane product, not a controller orchestrating several external engines.

Its comparison dimensions are default integration, explicit configuration/runtime-state governance and operating cost. Competitors overlap this surface; feature uniqueness and performance cannot be inferred from the integration or implementation language. See [scope](scope.md) and [performance acceptance](../verification/performance-bar.md).
