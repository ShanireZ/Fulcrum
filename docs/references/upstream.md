# Upstream references

- [Pingora](https://github.com/cloudflare/pingora): framework and contribution policy.
- [quiche](https://github.com/cloudflare/quiche): QUIC/HTTP3 sans-IO library.
- [Caddy](https://caddyserver.com/docs/): configuration and automatic HTTPS reference.
- [HAProxy](https://www.haproxy.org/): L4/L7 behavior reference.
- [nginx](https://nginx.org/en/docs/): server and proxy reference.
- [Open Knowledge Format](https://github.com/GoogleCloudPlatform/open-knowledge-format/blob/main/SPEC.md): bundle format. Concept docs have typed YAML frontmatter; index.md is navigation and log.md is reserved. Relative links keep this bundle usable in a standalone clone.

Versions/pins come from repository metadata. External references do not authorize adoption or external writes.
